# VFig: Vision Figure Generation

This repository contains the training code for **VFig**, a vision-language model trained to generate SVG figures from scientific paper images.

## Repository Structure

```
VFig/
├── rl/    # GRPO reinforcement learning training code
└── sft/   # Supervised fine-tuning code (coming soon)
```

## Getting Started

- For RL training, see [rl/README.md](rl/README.md).
